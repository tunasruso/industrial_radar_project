# System Context: Industrial Radar (LiderTex)

## 1. Общее описание

Проект «Промышленный радар» направлен на автоматический поиск и анализ изделий для производства на мощностях группы компаний «ЛидерТекс». Основной упор делается на импортозамещение (Bürkle, Hamilton, Swagelok) и дозагрузку простаивающего оборудования.

## 2. Стратегические цели

* **Импортозамещение:** Поиск и адаптация аналогов ушедших брендов (Bürkle, Hamilton, Swagelok) для рынков РФ и СНГ.
* **Дозагрузка мощностей:** Поиск заказов в первую очередь для простаивающих станков:
  * **Lasermann LSS 1325** (лазерный раскрой листовых материалов).
  * **UVGS-TFS-3008 (U07)** (фрезеровка/гравировка).
  * **Лазерный маркер (U19)** (маркировка шкал, логотипов).
  * **Печь DM-12NT-CVD-150 (U18)** (термообработка и покрытия).


* **Развитие USP:** Поиск ниш для уникального **кремниевого покрытия (Silicon Coating)** в агрессивных средах и искробезопасных изделий (латунные цепи).

## 3. Технические параметры (Production DNA)

* **Материалы:** Нержавеющая сталь (316L, 12Х18Н10Т), Латунь, Алюминий, Полимеры. **Титан — исключен.**
* **Давление:** Изделия до **15 МПа**. Все, что выше — зона высокого риска.
* **Резьбы:** Приоритет — метрическая. Вторично — G и NPT для импортозамещения.
* **Точность:** Изделия серийного и мелкосерийного типа.

## 4. Экономические и рыночные рамки

* **Стоимость часа:** Базовая ставка — **1000 руб./час**.
* **География:** РФ, Казахстан, Беларусь, Киргизия.
* **Целевые отрасли:** Нефтегазовая промышленность, Нефтехимия, Агропром, Лабораторное оборудование, Экология.
* **Ограничения:** **Запрещено** предлагать изделия медицинского назначения (отсутствие сертификации).

## 5. Методология работы агента

Система должна работать по 3-слойной модели:

1. **Directives (SOP):** Использование инструкций из папки `/directives/`.
2. **Orchestration:** Агент управляет процессами, используя навыки из `.agent/skills/`.
3. **Execution:** Вся математика и поиск данных выполняются через Python-скрипты в `/execution/`.

Этот файл — первое, что «читает» агент при активации. Он задает жесткие фильтры:

* Агент будет отдавать приоритет заказам на листовой раскрой (из-за Lasermann).
* Агент будет автоматически считать выгоду исходя из 1000 руб./час.
