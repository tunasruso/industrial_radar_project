# System Context: Industrial Radar (Laboratory Technologies)

## 1. Общее описание
Проект «Промышленный радар» для компании **«Лабораторные технологии»** (laboff.ru). Цель — поиск изделий для производства на собственных мощностях предприятия (металлообработка, работа с полимерами и стеклом).

## 2. Стратегические цели
* **Импортозамещение:** Поиск аналогов Bürkle, Hamilton, Swagelok для нужд химических и нефтегазовых лабораторий РФ и СНГ.
* **Дозагрузка мощностей:** Приоритет станкам Lasermann LSS 1325, UVGS-TFS-3008 и лазерной сварке.
* **Технологическое лидерство:** Продвижение изделий с кремниевым покрытием (Silicon Coating) для агрессивных сред.

## 3. Экономические рамки
* **Ставка:** 1000 руб./час.
* **География:** РФ, Казахстан, Беларусь, Киргизия.
* **Ограничение:** Никаких медицинских изделий (только промышленная химия и лаборатории).

## 4. Технические параметры (Production DNA)

* **Материалы:** Нержавеющая сталь (316L, 12Х18Н10Т), Латунь, Алюминий, Полимеры. **Титан — исключен.**
* **Давление:** Изделия до **15 МПа**. Все, что выше — зона высокого риска.
* **Резьбы:** Приоритет — метрическая. Вторично — G и NPT для импортозамещения.
* **Точность:** Изделия серийного и мелкосерийного типа.

## 5. Целевые отрасли
* Нефтегазовая промышленность
* Нефтехимия
* Агропром
* Лабораторное оборудование
* Экология

## 6. Методология работы агента

Система работает по 3-слойной модели:

1. **Directives (SOP):** Использование инструкций из папки `/directives/`.
2. **Orchestration:** Агент управляет процессами, используя навыки из `.agent/skills/`.
3. **Execution:** Вся математика и поиск данных выполняются через Python-скрипты в `/execution/`.
