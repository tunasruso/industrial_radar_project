# SOP: Поиск рыночных сигналов

## 1. Источники поиска
- **Тендеры:** B2B-Center, Госзакупки РФ, тендерные площадки Казахстана (Goszakup.gov.kz), Беларуси и Киргизии.
- **Конкуренты:** Мониторинг сайтов Bürkle, Hamilton, Swagelok, Хроматек, ООО Цвет.
- **Коды ТН ВЭД:** Обязательная фильтрация по списку из `data/reference/tn_ved_list.json`.

## 2. Поисковые запросы
Использовать комбинации: 
- "Аналог [Имя_Бренда] + [Название_Изделия]"
- "Закупка вентили нержавеющая сталь NPT"
- "Пробоотборник для нефтепродуктов ГОСТ"
- "Нестандартные метизы из нержавейки"

## 3. Критерии фильтрации
- Страны: РФ, Казахстан, Беларусь, Киргизия.
- Материалы: Только те, что указаны в `factory_specs.csv` (316L, 12Х18Н10Т, Латунь, Алюминий).
- Исключить: Медицинские изделия.

## 4. Выходные данные
Сохранять найденные сигналы в `data/output/market_signals.json` с указанием ссылки, цены и требуемого объема.
